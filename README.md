# AI Interview Coach

An AI-powered interview preparation and coaching web application designed to help users practice interview questions, improve their answers, and receive useful feedback.

## 🚀 Features

* 🎯 AI-powered interview question generation
* 💬 Interactive interview practice
* 🧠 Answer analysis and feedback
* 📊 Interview performance evaluation
* 🌐 Web-based user interface
* ⚡ Flask-based backend
* 📁 Organized frontend using HTML, CSS, and JavaScript

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **HTML5**
* **CSS3**
* **JavaScript**
* **AI / Natural Language Processing**
* **Git & GitHub**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/pundlachandu1703/AI-Interview-Coach.git
```

### 2. Open the project folder

```bash
cd AI-Interview-Coach
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Flask application:

```bash
python app.py
```

Then open your browser and visit:

```text
http://127.0.0.1:5000
```

## 💡 How It Works

1. The user opens the AI Interview Coach application.
2. The user starts an interview session.
3. The application presents interview questions.
4. The user provides answers.
5. The interview engine processes the responses.
6. The application provides feedback to help improve interview performance.

## 🎯 Project Objective

The main objective of this project is to provide an interactive platform where students and job seekers can practice interviews and improve their communication, technical knowledge, and confidence before attending real interviews.
